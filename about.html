About Kezio

Kezio is a collection of free web tools and Telegram bots built to be useful, simple, and easy to access.

Kezio brings these projects together in one place, so you can discover and access them without having to look through different websites and platforms.

Some tools are web-based and work in your browser. Others are Telegram bots you can use directly from the Telegram app. More tools will be added over time as I build them.

Why Kezio exists

Kezio started as a way to give the smaller projects I build a proper home. Instead of leaving useful tools scattered across different platforms, I wanted one place where they could be found and used.

Kezio is a directory for projects that may be useful to other people. Each tool is independent, and the way you use it depends on the project.

What you'll find here

Every tool on Kezio is an independent project. The collection includes:

  • - Web tools: browser-based utilities you can use in your browser.
  • - Telegram bots: tools you can use directly through Telegram.

Some tools are hosted here. Others live on their own domains or platforms. The directory brings them together so you can find what you need.

Who's behind Kezio

Kezio is built by Karo Junior, a developer who works on web apps, Telegram bots, Android apps, games, and other software projects.

You can see more of my work on my personal website.

What's next

More projects will be added as they are built. They may be web tools, Telegram bots, or something else.

Have an idea for a useful tool? Send it through the contact page.
